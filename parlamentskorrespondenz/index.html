Ausprobieren

Abruf direkt aus deinem Browser an parlament.gv.at (die API erlaubt das per CORS). Gezeigt werden nur die ersten 8 Zeilen, ohne Titel.

Die Doku nennt 14 Spalten.

GET/aktuelles/pk/jahr_2022/pk1407?json=trueDetailseite (Geschichtsseite)

Die Geschichtsseite einer einzelnen Gegenstandsnummer als JSON. Den Pfad liefert HIS_URL aus der Ergebnisliste. Der Parameter json=true ist in den Datensatzbeschreibungen nicht dokumentiert, funktioniert aber.

Nicht gegen die API geprüft: Der Pfad stammt aus dem Link der Ergebnisliste, die Felder aus der Doku.

Beispiel

curl -s 'https://www.parlament.gv.at/aktuelles/pk/jahr_2022/pk1407?json=true'

Beobachtungen

  • Die Spalten Datum (1, 5, 12) und Titel (2, 7) sind mehrfach vorhanden.
  • Abothemen in der Doku-Beispielzeile wiederholt „Parlament und Demokratie“ dreimal.
  • Die Doku-Schemas sind als JSON ungültig (fehlende Kommas, leeres header).
Lizenz: Die Meldungen stehen unter CC BY 4.0, die Doku erlaubt Weiterverwendung von Ergebnislisten, API und Detailseiten inklusive Text.
