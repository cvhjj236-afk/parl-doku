Ausprobieren

Abruf direkt aus deinem Browser an parlament.gv.at (die API erlaubt das per CORS). Gezeigt werden nur die ersten 8 Zeilen, ohne Titel.

GET/ausschuss/XXVIII/A-PB/1/00932?json=trueDetailseite (Geschichtsseite)

Die Geschichtsseite einer einzelnen Gegenstandsnummer als JSON. Den Pfad liefert HIS_URL aus der Ergebnisliste. Der Parameter json=true ist in den Datensatzbeschreibungen nicht dokumentiert, funktioniert aber.

Die Doku beschreibt keine Detailfelder („in der JSON-Beschreibung“). Der Pfad liegt unter /ausschuss/…, nicht /gegenstand/…. Beobachtet (content ist ein Objekt):

Beispiel

curl -s 'https://www.parlament.gv.at/ausschuss/XXVIII/A-PB/1/00932?json=true'

Beobachtungen

  • Die Doku zeigt rows als flache Liste, real ist es ein Array aus Arrays.
  • AUS_ART kennt nicht die in der Doku erwähnten Untersuchungsausschüsse als eigenen Wert; Zuordnung unklar.
  • Das Doku-Beispiel (NR, XXVIII) zeigt eine BR-Zeile aus 2000 bis 2015.
  • Agenda-Links nutzen in der Doku den Host iwww.parlament.gv.at.
